# DanielCutting.com — v2

Static site. Drop this folder into your repo as `/v2` and GitHub Pages will serve it at `/v2/`.

## Contents
- index.html — homepage (video hero, stats, doors, events, camps, Daniel & Joshua, brands, about, contact)
- events.html, daniel-and-joshua.html, brands.html, about.html, camps.html, contact.html
- support.js — runtime the pages load (must sit alongside the HTML)
- assets/ — photography and client logos
- .nojekyll — stops GitHub Pages ignoring files it otherwise would

## Notes
- Hero video streams from YouTube; nothing to host.
- Social icons load from cdn.simpleicons.org.
- Forms are visual only — no submission endpoint wired up yet.
- Campaign view counts are placeholders marked "Views · TBC".
